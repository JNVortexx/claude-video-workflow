# Claude-Code Video-Workflow – Starter-Kit

1. Claude Code im leeren Projektordner starten (`claude`).
2. `MASTERPROMPT.md` in den Chat ziehen (oder: „Lies MASTERPROMPT.md und richte alles ein“).
3. Rohschnitt + SRT in den Ordner legen, Prompt-Vorlage aus Kapitel 12 benutzen.

Inhalt: `MASTERPROMPT.md` (der ganze Workflow) · `starter/` (Code zum Kopieren) · `tools/` (Analyse-Skripte) · `examples/day193/` (Referenz-Video).
Nicht enthalten: Schriften, Sounds, Footage, API-Keys – bitte selbst beschaffen (Lizenzen).
